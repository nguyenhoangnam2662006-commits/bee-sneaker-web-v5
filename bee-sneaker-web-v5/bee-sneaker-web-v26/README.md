# Bee Sneaker V26

V26 thêm tính năng gom sản phẩm theo **Dòng sản phẩm / Nhóm mẫu** để danh sách dễ tìm hơn.

- Ví dụ: Samba là một nhóm, bên trong là Samba Nâu, Samba Mesh, Samba Quai Dán...
- Các nhóm thu gọn/mở rộng như accordion.
- Form thêm/sửa sản phẩm có ô **Dòng sản phẩm / Nhóm mẫu**.
- Dữ liệu cũ có chữ Samba được tự động gom vào nhóm Samba.
- Tìm kiếm hỗ trợ cả tên nhóm.
- Giữ nguyên database và các chức năng V25.
