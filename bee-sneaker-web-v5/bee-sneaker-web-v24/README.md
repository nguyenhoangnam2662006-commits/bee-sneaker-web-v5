# Bee Sneaker V24 — đăng ký bằng SĐT & đối soát đã trả

V24 kế thừa V23 và thêm:
- CTV mới đăng ký bằng **số điện thoại + mật khẩu**.
- SĐT là duy nhất và được dùng làm mã nhận diện/đăng nhập của CTV mới.
- Tài khoản CTV cũ vẫn đăng nhập bằng username cũ để không mất dữ liệu.
- Trang đối soát hiển thị SĐT CTV.
- Mỗi đơn có trạng thái **Chưa trả / Đã trả CTV**.
- Chỉ đơn **Hoàn thành** hoặc **Hoàn** mới được đánh dấu đã trả.
- Có thể tích chọn từng đơn để đánh dấu đã trả hoặc bấm **Đã trả tất cả** theo CTV.
- Mỗi lần trả tạo **mã đợt đối soát** và lưu thời gian thanh toán.
- Đơn Hoàn vẫn tính -45.000đ, đơn Hủy = 0đ.
- Dữ liệu cũ được giữ nguyên; database tự thêm cột cần thiết.
